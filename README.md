# 🌟 Gemini Multimodal Interface

An interactive AI application powered by **Google Gemini 1.5 Flash** that supports both **text generation** and **image understanding** in a single seamless interface.

Built with **Python + Gradio**, this project demonstrates practical implementation of multimodal AI systems and modern GenAI workflows.

## 🚀 Features

* 🖊️ AI-powered text generation using Gemini 1.5 Flash
* 🖼️ Image analysis & visual understanding
* 📋 Combined text + image prompting
* 🎨 Clean Gradio-based web interface
* ⚡ Fast, lightweight, and responsive
* ☁️ Google Colab compatible

---

## 🧠 Project Overview

This application enables users to interact with Google’s Gemini model using:

* Text-only prompts
* Image-only inputs
* Mixed multimodal queries

The model can analyze images, answer questions about visuals, generate contextual responses, and handle multimodal reasoning tasks in real time.

## ⚡ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Tanmay1112004/gemini-multimodal-interface.git
cd gemini-multimodal-interface
```

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 3️⃣ Add Gemini API Key

```python
GOOGLE_API_KEY="your_api_key"
```

### 4️⃣ Run Application

```bash
python app.py
```
